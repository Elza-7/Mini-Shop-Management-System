# 🏪 Mini Shop Management System

A beginner-friendly Python project designed to manage products and inventory for a small retail shop.

## 🚀 Features

- Add Products
- View Products
- Store product names, prices, and quantities
- Manage product information

## 🛠️ Technologies Used

- Python
- Lists and Dictionaries
- PyCharm
- Git & GitHub

## 📂 Project Structure

```text
Mini-Shop-Management-System/
│
├── shop_management.py
├── README.md
└── .gitignore
```

## ⚙️ How to Run

1. Clone this repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

2. Open the project folder.

3. Run the application:

```bash
python shop_management.py
```
